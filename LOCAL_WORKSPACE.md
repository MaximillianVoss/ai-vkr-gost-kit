# Локальная рабочая структура

Этот репозиторий относится к особо важным проектам. Не перемещайте, не
переименовывайте и не удаляйте его каталоги, не объединяйте рабочие деревья и не
выполняйте массовые изменения без прямого указания пользователя.

Канонические локальные каталоги Windows с 2026-07-15:

- основное рабочее дерево `main`:
  `X:\Проекты\Генератор пояснительных записок`;
- связанное рабочее дерево `codex/sync-schemegen-updates`:
  `X:\Проекты\Инструменты ВКР по ГОСТ\ai-vkr-gost-kit-sync`;
- самостоятельный исторический проект схем:
  `X:\Проекты\Генератор схем`.

`ai-vkr-gost-kit-sync` является Git worktree этого же репозитория, а не
независимым клоном. Перед изменениями проверьте `git worktree list`, ветку,
remote и полный `git status --short --branch` в обоих рабочих деревьях. Не
индексируйте и не удаляйте чужие незакоммиченные файлы.

Старые пути под `C:\Users\FossW\OneDrive\Репетиторство\Программирование` не
являются источником истины после миграции. Исходные временные метки и пофайловые
SHA-256 сохранены в локальном отчете миграции вне репозитория.

Перед работой прочитайте `AGENTS.md`. При оформлении пояснительных записок
используйте шаблоны и ГОСТ-стили этого репозитория; правила именования и
публикации репозиториев задает
`https://github.com/MaximillianVoss/repository-governance`.
