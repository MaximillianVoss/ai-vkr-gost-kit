# Word VBA Макросы Для ГОСТ-Оформления

`GostFormatting.bas` - актуальный модуль макросов для Word. В нем сохранены имена старых процедур:

- `РисункиФорматирование` - спрашивает выравнивание рисунков, максимальную ширину и режим нумерации; уменьшает слишком широкие рисунки пропорционально и не растягивает маленькие.
- `ТаблицыФорматирование` - форматирует таблицы, повторяет первую строку как заголовок и добавляет подпись только если рядом с таблицей ее нет.
- `ОбновитьНумерациюЗаголовков` - обновляет заголовки верхнего уровня: может добавить префикс `Глава N.` и привести текст к выбранному регистру.
- `AlignTablesAndFigures` и `UpdateGostHeadingNumbering` - англоязычные алиасы для явного запуска через `word_agent_toolkit.py --macro`. Они сохраняют диалоги Word и не предназначены для полностью безоператорного запуска; для него используйте встроенную Python COM-постобработку.

`legacy/` содержит побайтовые исходные версии макросов из папки `Репетиторство` без исправлений. Их SHA-256, размеры и исходные даты 2024 года записаны в `legacy/SOURCE_METADATA.json`. Git не хранит временные метки файлов, поэтому даты вынесены в отдельные машиночитаемые метаданные.

## Установка В Word

Из корня репозитория:

```powershell
.\word-vba\install_gost_macros.ps1
```

Скрипт импортирует `GostFormatting.bas` в `Normal.dotm` как модуль `GostFormatting`. Если уже есть модуль `GostFormatting` или стандартный модуль с процедурами `РисункиФорматирование`, `ТаблицыФорматирование`, `ОбновитьНумерациюЗаголовков`, `AlignTablesAndFigures`, `UpdateGostHeadingNumbering`, он сначала экспортируется в `word-vba/backups/`, затем заменяется.

Если Word возвращает ошибку доступа к VBA-проекту, включите в Word:

`Файл -> Параметры -> Центр управления безопасностью -> Параметры центра управления безопасностью -> Параметры макросов -> Доверять доступ к объектной модели проектов VBA`.

## Поведение Подписей

Макросы ищут ближайший непустой абзац рядом с объектом: для таблиц - сверху, для рисунков - снизу. Если рядом уже есть подпись нужного типа или абзац со стилем подписи, новая подпись не вставляется. Это защищает от повторного запуска макроса и дублей вроде двух подписей `Таблица 1`.

## Проверка

Статическая проверка не изменяет `Normal.dotm` и не запускает Word:

```powershell
.\word-vba\tests\Test-GostFormatting.ps1
```

Она проверяет публичные процедуры, ключевые правила форматирования, синтаксис установщика и SHA-256 исторических файлов. Полноценную проверку поведения VBA следует выполнять на отдельном тестовом документе Word.
